# مقسّم الصور | LP Splitter

أداة ويب بسيطة تقسّم صورة واحدة إلى **8 أو 10 صور WebP مضغوطة**:
الصورة تنقسم أولًا إلى **نصفين بالعرض** (عمودان)، ثم كل نصف ينقسم عموديًا إلى **4 أو 5 أجزاء**.

## ✨ المميزات

- 📤 رفع بالضغط أو السحب والإفلات (JPG · PNG · WebP)
- ✂️ تقسيم ثابت: عمودان × عدد صفوف قابل للضبط من 1 إلى 10 (4 ← 8 صور، 5 ← 10 صور)
- 🔢 **ترقيم واضح لكل شريحة** (1، 2، 3…) + اسم الملف يبدأ بنفس الرقم (`slice_01_r1-c1.webp`) فيرتّبها مدير الملفات تلقائيًا من الأعلى إلى الأسفل
- 🗜️ ضغط WebP بجودة قابلة للضبط (10–100%)، مع سقوط تلقائي إلى PNG في المتصفحات التي لا تدعم WebP
- 📐 كل شريحة تُصدَّر **بعرض الصورة الأصلية الكامل** (تكبير متناسب)، مع حقل اختياري لتحديد عرض مخصص
- 👀 معاينة حيّة لشبكة التقسيم فوق الصورة الأصلية
- 📦 تحميل الشرائح فرادى أو كلها دفعة واحدة كملف ZIP
- 🔒 كل المعالجة داخل المتصفح — لا يُرفع أي شيء إلى أي خادم
- 🌙 واجهة عربية كاملة (RTL) بتصميم بسيط (Tailwind CSS)

## 🚀 التشغيل

```bash
cd G:\Projects\lp-splitter

npm run dev
```

ثم افتح: http://localhost:5173

## 📦 البناء للإنتاج

```bash
npm run build
```

تُنتَج الملفات الجاهزة للنشر في مجلد `dist/`، ويمكن استعراضها محليًا بـ:

```bash
npm run preview
```

## 🖱️ طريقة الاستخدام

1. **ارفع الصورة** — اضغط على المربع أو اسحب الصورة إليه
2. **اضبط الإعدادات**:
   - عدد الأجزاء العمودية لكل نصف (الأزرار السريعة 3/4/5/6 أو رقم مخصص 1–10)
   - جودة الضغط (75–85 توازن جيد)
   - بادئة أسماء الملفات
   - عرض الشريحة (اتركه فارغًا لعرض الصورة الأصلية)
3. **اضغط «قسّم»** — تظهر الشرائح مرقّمة بالترتيب
4. **حمّل** شريحة واحدة بزر «تحميل» أو الكل بزر «تحميل الكل ZIP»

> أي تغيير في عدد الصفوف أو الجودة أو العرض يُعيد التقسيم تلقائيًا.

## 🛠️ التقنيات

- React 18 + Vite 5
- Tailwind CSS 3
- JSZip (لملف ZIP)
- Canvas API (التقسيم والترميز إلى WebP) — بدون أي مكتبات معالجة صور
